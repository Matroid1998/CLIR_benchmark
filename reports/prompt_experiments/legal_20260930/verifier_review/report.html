Verifier performance against the manual review

Revised verification retains more intrinsically good question–answer pairs but also accepts a larger proportion of weaker pairs. Ranking does not show a consistent improvement. These are descriptive results on each version’s own generated questions, not a controlled test of three verifiers on the same fixed candidate bank.

Manual reference:717 individually reviewed candidates from40 documents. A good pair means question score at least4/5 and no major answer defect. This proxy does not require compliance with every mode or metadata rule, so some rejected good questions may have valid operational reasons for rejection. Manual labels are agent judgments, not human gold labels.

Concrete source checks

  • EUR-Lex paper rolls: a legitimate threshold application received grounding/precision3/3 originally,4/4 revised, while revised lookup received5/5 for the same answer span. The penalty softened but remained. Question wording also changed, so this does not isolate a causal verifier effect.
  • Finnish VAT category membership: original and revised valid category questions both received quality15/25 and total29/40. Both verifier rationales demanded grandfathering/social-reason conditions needed for ultimate exemption entitlement, although the question asked only whether the supply belonged to a listed category.
  • UN CEDAW724: the Simple verifier correctly identified a question attributing Ms Tan’s request to Ms Zou. It assigned grounding2/5 and a blocking audit. A weak generated question therefore does not automatically imply a weak verifier.
  • EUR-Lex copyright: the Simple verifier correctly described a circular question/answer-type mismatch and scored it28/40, but classified the audit as minor_issues. The ranking put it last, yet the diagnostic acceptance gate still let it through. Recognition of a defect and appropriate gate severity are distinct capabilities.

Limitations

  • No controlled fixed-candidate-bank comparison of all three verifier prompts was run. Across all1778 candidates, exact whitespace-normalized QA overlap is only1 original/revised pair and1 revised/simple pair; none across all three.
  • Generation quality, number of candidates, mode policies, metadata validity, and candidate difficulty differ by version. Descriptive rates cannot isolate verifier accuracy improvements.
  • Manual judgments are agent ratings rather than human gold labels; only40of100 documents reviewed.
  • Good intrinsic questions may legitimately fail intended mode or metadata requirements; withheld does not automatically mean an erroneous rejection.
  • Highest native total includes answer faithfulness, while primary manual ranking measures question quality. Answer-aware ranking is supplied separately.
