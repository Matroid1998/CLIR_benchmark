The pipeline reruns and routing experiments are complete. The shared quality evaluation is incomplete. It has graded 424 of 1,778 candidate memberships. Funding or a different shared judge is needed for the rest. No overall quality winner is claimed from this partial coverage.

Local MLflow now versions the prompts without an account or API key. The original, bias-adjusted and simpler bundles are preserved as immutable versions, and the bias-adjusted bundle is active for subsequent legal runs. What the evidence establishes

There are both real generation defects and residual model grading preferences. For a paper-roll tariff case, the revised faithfulness grader assigns 4/5 grounding and 4/5 precision because the reader must connect stated measurements to explicit thresholds. A revised lookup receives 5/5 and 5/5 with the identical answer. The revised rubric expressly permits that application. This is evidence of inconsistent enforcement, rather than proof that the evidence span is intrinsically worse.

Other differences are legitimate. The baseline banana-reporting scenario omitted the product; its revised question identifies bananas and the reporting context. Some UN practitioner questions omit the country or time, and one attributes the General Assembly President's statement to Saint Lucia. Those are substantive generation defects. The case reviews distinguish these problems from unjustified penalties.

The original EUR-Lex router already supported suitable fact patterns. Its generator backend selected them for 37/50 targets while Jev selected none. The revised tie rule strengthens the preference for a supported case; it does not remove an explicit original lookup priority. Likewise, the original fact-pattern quality rubric already allowed condition matching and category-only questions. The revisions reinforce those permissions and align them with conflicting shared faithfulness instructions.

Concrete prompt mechanisms include the old faithfulness demand for “No inference whatsoever”, treating ordinary referent resolution as a score-3 inference, rarity rules for score 5, and excessive brevity pressure. UN's stricter practitioner framing, anchor requirements and exclusions of particular requests/proposals narrowed its eligibility. Requests and proposals are now allowed with their status preserved. Attributed facts were already allowed in the original prompts.

UN routing also has an unresolved definition problem: lookup is distinguished by a searcher's source-seeking intent, while the decider receives document text. The same passage can support a specialist question or a source lookup. This ambiguity remains even after reducing arbitrary restrictions.

The shorter UN Jev router was not promoted. The revised bundle remains the default while the shared quality comparison is unfinished. The compressed variants and both crossed routers remain registered and reproducible.

Limits of the quality evidence

The common evaluator uses a fixed, mode-blind rubric; identical question–answer pairs are graded once, and versions and requested mode labels are hidden. It is still the same verifier model, not a human gold standard or a measured retrieval test. Manual review caught an incorrect claim that an answer omitted “periodicals” although the word is present, another irrelevant VAT-condition penalty, and an unsupported assumption about banana production in Cyprus. These grades remain unchanged in the saved data, with the errors documented separately.

This is one generation per target/mode/version, on the diagnostic sample used for revision. It is not a held-out generalization test. Only English was evaluated. Whole-bundle changes combine generation, routing and grading changes; the separate UN routing experiment isolates two prompt blocks. Best-of-batch quality and native rank-1 quality are reported separately, with missing scores excluded rather than set to zero.

Remaining work and reproducibility

OpenRouter rejected concurrent requests because of its in-flight credit-reservation limit. After those requests settled, the account had $2.70 remaining. The remaining 253 shared-judge batches are estimated at roughly $5.20 based on completed-call costs; actual cost may vary. The evaluation can resume with two workers and a larger attempt budget, reusing all completed grades. Switching to the existing OpenAI key would require a new shared evaluation across all three versions.

All 27 failed native grading batches in the two new runs were recovered from saved responses without new model calls or changes to numeric grades. Exact candidate IDs and full schemas were validated, and each structural repair has its own audit trail.

Validation: 753 tests passed with the active registered bundle; Ruff and git diff --check passed. The existing prompt-format test cannot run because scripts/format_prompts.py is missing; this task did not remove it.
