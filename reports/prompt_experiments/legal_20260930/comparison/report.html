Interpretation limits

  • Single generation per target/mode/version; model sampling remains variable.
  • Same diagnostic sample is used for revision and evaluation; not a held-out generalization test.
  • Operational verifiers change with variants; only common-evaluator scores are comparable across versions.
  • All scored generation is English; other languages are versioned but not evaluated.
  • The common judge is the same verifier model with a frozen revised rubric; this is not human validation or a measured retrieval evaluation.
  • Several prompt clauses and eligibility rules change together, so this comparison does not isolate individual causal effects.
  • Best-of-batch common scores can favor modes producing more candidates; candidate counts, usable coverage and native rank1 diagnostics are reported separately.

Common best-any and best-usable scores select the best available candidate under the common evaluator (an oracle). It is not an actual delivered winner: screening exports leave is_best false until a separate best export. No ranking is reconstructed here. Regret is the common oracle score minus the common score of native rank1. Missed usable counts targets where rank1 failed the common usability gate although another candidate passed.
